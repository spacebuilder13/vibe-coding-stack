# Notice

This skill is an English-language adaptation of **Ian Xiaohei Illustrations**, an AI-agent skill created by Ian, ported for Cursor's agent with native image generation.

Source repository (MIT licensed): <https://github.com/helloianneo/ian-xiaohei-illustrations>

The recurring character "Xiaohei" (小黑) is part of Ian's visual language for article illustrations. This adaptation keeps the character and credits Ian per the source repository's NOTICE.

Example images for occasional style calibration live in the source repo's `examples/images/` directory — they are intentionally not vendored here. Use them only to calibrate line density, whitespace, color restraint, and Xiaohei's demeanor; never copy their compositions (see `references/composition-patterns.md`).
