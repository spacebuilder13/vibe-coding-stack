# Composition Patterns and Originality Rules

## Base structure types

Pick one structure per image — do not mix too many.

### Workflow

Good for: input -> processing -> output, content production, AI workflows, automation chains.

How: input on the left, Xiaohei or a strange machine processing in the middle, output on the right, orange arrows for the main flow.

### System slice

Good for: information sources, filters, databases, renderers, one corner of an agent system.

How: draw only 3–5 core modules; Xiaohei participates in one key action.

### Before / after

Good for: chaos/order, manual/automatic, scattered/gathered, anxious/stable.

How: chaos on the left, stability on the right, orange arrow in between. The character can be more exaggerated here.

### Character states

Good for: user pain points, creator moods, too many tools, information anxiety, stuck-to-running.

How: 2–4 small states, one short label each.

### Concept metaphor

Good for: content factory, information warehouse, black box of the mind, workflow machine, automated daily report.

How: one big strange object or machine, a few inputs, one output. Must be memorable.

### Layered method

Good for: methodology frameworks, system layers, capability stacks, layered content systems.

How: stacked boxes, never a formal pyramid; Xiaohei hauls bricks or builds at the side.

### Map / route

Good for: idea-to-launch, user journeys, content handoff paths, learning paths.

How: one winding path, few nodes, Xiaohei leading the line or walking it.

### Mini comic strip

Good for: failure-to-success, the real messy process, gentle complaints, before/after of using something.

How: 2–4 small panels, one action per panel.

## The original-metaphor method

Invent a fresh metaphor from the current article every time. Never recycle old images.

### Three steps

1. Turn the abstract concept into a physical action: getting stuck, leaking, getting heavier, sorting, settling, fermenting, opening a door, folding, unpacking, flowing back.
2. Turn the system structure into a low-tech object: a broken machine, cardboard box, drawer, water pipe, mailbox, weird dial, scale, well, ladder, strange workstation.
3. Give Xiaohei the action: not standing beside it, but stuck inside the machine, pulling the wrong line, guarding the gate, hauling, patching, weighing, holding the ladder, taking notes, stuffing things into a strange device.

### Object pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, water pipe, ball of yarn, floodgate, turntable, black box, hole punch, pasta press, clothesline, weird workstation.
- Pick only 1–2 per image — do not pile them up.

### Xiaohei action pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, dismantle, mark, recycle.
- The action must serve the core idea — never weird for weirdness' sake.

## Anti-copying rules

Do not open or replicate the original repo's example images by default. They exist only for style calibration: line density, whitespace, color restraint, Xiaohei's demeanor.

Unless the user explicitly says "copy this one / replicate this composition / edit this example", never directly reuse these known compositions:

- Conveyor belt with two breakpoints
- Xiaohei pulling the judgment lever inside a content machine
- Xiaohei as a funnel sorting traffic/trust/conversion
- Xiaohei cutting the "content fish"
- Xiaohei leading the handoff path
- Xiaohei pulling three layers of information sources
- Three Xiaoheis with megaphone/bridge/door
- Xiaohei stamping the copy toolbox
- Xiaohei holding a sign over the common-pitfalls path

Even for the same topic, invent a new metaphor. E.g. a "handoff path" doesn't have to be a route — Xiaohei could tie the content's tail to a door handle; "one input, many outputs" doesn't need a fish — Xiaohei could press one paper ball into several shapes.
