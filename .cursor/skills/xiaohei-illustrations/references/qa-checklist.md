# QA Checklist

## Must pass

- It is 16:9 horizontal.
- The background is clean white.
- Xiaohei is present.
- Xiaohei carries the core action, not just decoration.
- No old example composition was replicated — a new metaphor was invented for this article.
- The image is absurd, creative, and interesting.
- Clean and airy — the subject takes up no more than ~60% of the frame.
- One image explains only one core structure.
- English labels are few, short, and readable (max 5–8 labels, 1–4 words each).
- Orange is used only for the main path or arrows.
- Red is used only for key points, problems, warnings, or results.
- Blue is used only for secondary notes, feedback, or system state.

## Failure signals

Regenerate or locally edit if any of these appear:

- A top-left title like "Common Pitfalls / Workflow / System Architecture / Roadmap".
- Xiaohei looks like a mascot, a meme sticker, or a cute cartoon.
- The image looks like PPT, course slides, or a formal flowchart.
- Too many elements, too many arrows, too many nodes.
- Text has grown into paragraphs of explanation.
- Background has paper grain, shadows, gradients, beige tint, or noise.
- Real UI screenshots or techy interfaces.
- Serious misspellings or unreadable labels.
- The image is stiff, with no absurd metaphor.
- Too similar to a known example composition from the source repo.

## Iteration moves

- Too plain: make Xiaohei the subject of the action and add one strange-but-coherent metaphor.
- Too complex: delete nodes; keep one action and 3–5 short labels.
- Too cute: emphasize deadpan, blank serious expression, not cute, not mascot.
- Too PPT: remove titles, borders, tidy grids, and excess arrows; redraw as a hand-drawn scene.
- Too close to an old example: keep the core idea, swap the main object and Xiaohei's action.
- Text errors: prefer local edits; if errors are widespread, regenerate with fewer labels.

## Delivery bar

A high-quality image should make the reader think "that's a bit odd" first, then grasp the structure within one second.

If the first impression is a tutorial page instead of an absurd product sketch on blank paper, it fails.
